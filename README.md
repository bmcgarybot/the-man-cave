# 🏟️ The Man Cave

A premium PWA sports dashboard — built as a birthday gift.

**Live at:** [https://bmcgarybot.github.io/the-man-cave/](https://bmcgarybot.github.io/the-man-cave/)

## Features

### 🏀⚾🏈 Sports
- **NBA** — Live scores, game schedules, favorite team cards (Clippers, Suns, Warriors)
- **MLB** — Full scoreboard with team logos and live game indicators
- **NFL** — Scoreboard with game status
- **College Basketball, Football, Baseball** — All scoreboards
- **NBA News** — Latest headlines from ESPN

### 🌤️ Weather
- **Auto-detects your location** via GPS geolocation
- **Search any city** with the built-in weather search
- **7-day forecast** with weather icons
- **Falls back to Kingman, AZ** if location access is denied
- Powered by the National Weather Service API (free, no key needed)

### 🔥 Fire Watch
- Active wildfire monitoring near your detected location
- Distance from you, acreage, containment percentage
- Powered by NIFC/ArcGIS (free, no key needed)

### 📱 PWA (Progressive Web App)
- Install to your iPhone/Android home screen
- Looks and feels like a native app
- Offline caching via service worker
- Auto-refreshes every 2 minutes

## Tech Stack
- Pure HTML/CSS/JavaScript — no frameworks, no build tools
- ESPN public API (free, no key)
- NWS API (free, no key)
- NIFC ArcGIS (free, no key)
- Nominatim/OpenStreetMap for geocoding (free)
- GitHub Pages for hosting (free)

## How to Use
1. Visit the URL above on your iPhone
2. Tap the Share button → "Add to Home Screen"
3. Open from your home screen — it's now an app!
4. Allow location access for local weather (or search any city)
